    About the Windows security warning
    Windows may show “Microsoft Defender SmartScreen prevented an unrecognized app” because this preview is not digitally signed yet. That warning is about the publisher reputation/signature, not proof that the file is malicious. Only use the installer linked here. We’ll work toward proper code signing when the project is ready.
    Good to know

    Frequently asked questions

    Do I need Logitech G HUB or other wheel software?

    Use the official software recommended for your wheel. WheelBridge will not include manufacturer software. The exact requirements will be confirmed after testing each supported device.

    Does WheelBridge support every racing wheel?

    Not yet. The current preview does not read physical wheel input. Compatibility will be listed only after individual devices have been implemented and tested.

    Will WheelBridge work with every Roblox game?

    No. The long-term plan is to support Roblox experiences that add WheelBridge integration. That connection is not implemented in this preview.

    Will I need to pay?

    The plan is to make the WheelBridge app free to download. Any future costs or limitations will be explained clearly.

    Is the download available now?

    Yes. The button downloads the Windows installer (.exe) directly from the official WheelBridge GitHub release. It currently contains the app interface and simulated input sliders only; it cannot read a real wheel or connect to Roblox yet. Please avoid unofficial downloads.
